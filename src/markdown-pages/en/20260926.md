title: "Orca Didn't Quite Fit Me, So I Released Hawky"
---

There's an IDE called Orca.

[Orca](https://www.onorca.dev/)

I'd been wondering what "IDE" even meant, and it turns out it stands for Integrated Development Environment. So I guess Cursor and Eclipse are IDEs too?

---

So what is Orca, exactly?

Roughly speaking, it's an impressive app that lets you run multiple Codex or Claude Code sessions at the same time across multiple repositories (not only repositories, but let's keep it simple).

It can also run several sessions on a single question and pick the best answer from among them. Pretty amazing.

---

That said, having only played with it a little, and speaking only about where it stands right now, Orca felt like more than I could make use of.

I usually work on two or three repositories, running just one or two sessions in each at a time, so it felt a bit like overkill.

For that, running the Claude Code extension in Cursor covers almost everything I need.

---

Still, with Cursor or VSCode, I open several windows and run Claude Code in multiple tabs in each of them.

That has its own problems: I keep switching back and forth between windows, and I often miss it when a session in a window hidden in the background is waiting for my confirmation.

This was the one thing I really wanted to fix, and I'd been thinking about it on and off lately.

---

So I released [Hawky](https://hawky.kkweb.io), a menu bar app for Mac.

It's simple: when Claude Code is waiting for confirmation, it shows up in the menu bar, and from there you can jump straight to that window.

It also supports Native Tabs, so you no longer need to open multiple windows.

As a bonus, it also detects the idle state, so you can tell whether Claude Code is still working.

I also did a quick check in VSCode, so it should work there too.

---

Simple is best, and this much is just right for me.

If Orca feels like more than you need, I'd be glad if you gave Hawky a try.
