---

Orca という IDE がありまして。

[Orca](https://www.onorca.dev/)

IDE ってなんだよって思ってたんですが、統合開発環境（Integrated development environment）のことなんですね、Cursor や Eclipse も IDE なんですかね？

---

で、この Orca とはなんぞやと。

ざっくり言うと、複数のリポジトリ（に限らないですが、わかりやすさ重視で）で、複数の Codex や Claude Code のセッションを同時に走らせることができる、すごいアプリらしいです。

他にも 1 つの質問に対して複数のセッションを走らせて、その中から最適解を取得することができる強みがあるとか、すごすぎる。

---

ただこの Orca、少しだけ触った上であくまで現時点での話ですが、自分には少し持て余す感じがありまして。

基本的に 2, 3 のリポジトリに対し、それぞれ同時に 1, 2 本程度しか同時にセッションを走らせない自分なので、ちょっと大げさすぎるかなと。

であれば、Cursor で拡張機能の Claude Code を動かすくらいで、ほぼ困らないという。

---

とはいえ Cursor や VSCode の場合、複数のウィンドウを立ち上げて、それぞれで複数タブ開いて Claude Code を走らせる運用をしているのですが。

これはこれで複数のウィンドウで行ったり来たりしないといけないし、裏に回ったウィンドウ内で確認待ちが発生しても気付けない、みたいなことが多々ありまして。

こればっかりはなんとかしたいなと最近ぼちぼち考えていました。

---

ということで、[Hawky](https://hawky.kkweb.io/ja) という、Mac 向けのメニューバーアプリをリリースしました。

内容としてはシンプルで、Claude Code が確認待ち状態になったらメニューバーに表示してくれて、そこからそのウィンドウへ飛べる感じです。

Native Tabs 機能にも対応しているので、これで複数のウィンドウを開く必要もないです。

ちなみに、オマケで待機状態の判定も入れているので、Claude Code が作業中かどうかもわかるようになってます。

VSCode でも軽く動作確認は行ったので、おそらく動きます。

---

シンプルイズベスト、自分にはこれくらいがしっくり来ます。

Orca を持て余していましたら、ぜひ使ってもらえればと思います。
